Entry for the [make.fun bounty "The Funniest Out-of-Office"](https://make.fun/bounty/u-kreutzx-the-funniest-out-of-office-054815cf) — one line of an out-of-office auto-reply, the funniest I could make it, in 140 characters or fewer.

## The entry

> I'm out of office — my inbox finally filed a restraining order against me. Back when it drops the charges.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
```

`main.ts` writes the single-line entry to `/output/entry.txt` and prints it to stdout. It is fully deterministic: every run produces byte-identical output.
